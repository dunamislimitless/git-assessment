# Lomi Vibes

Lomi Vibes is a single-page HTML moodboard created as an AltSchool assessment. It presents a calm, cozy visual direction around the idea of slow living and quiet joy.

## About

The page pairs the message “soft vibes for the soul” with a warm, softly colored background and a centered, translucent content panel. Its short description and the tags “sunrise,” “cozy,” and “dreamy” reinforce the relaxed mood.

## Built With

- HTML5 for the page structure
- CSS for the layout, colors, gradients, typography, and responsive sizing
- No JavaScript, external assets, or package dependencies

## View the Page

Open `lomi.html` directly in a web browser. No installation or build step is required.
